# Дашборды

В Dispatch есть базовые дашборды и отчёты, которые помогают понять, как инциденты влияют на организацию. Из коробки доступны полезные сводки, например число инцидентов по типу и приоритету.

Кроме того, все графики на дашбордах динамические. Благодаря этому можно фильтровать данные по разным признакам инцидентов и находить интересные подмножества.
