# Обратная связь

При закрытии инцидента Dispatch отправляет всем его участникам личное сообщение с просьбой оценить, насколько они довольны тем, как был отработан инцидент, и оставить обратную связь. Отзывы участников сохраняются и показываются в разделе «Обратная связь» интерфейса, а также раз в день отправляются командиру инцидента по электронной почте.
