# Руководство пользователя

В Dispatch есть два _основных_ типа пользователей: командир инцидента и участник инцидента.

Командир инцидента отвечает за то, чтобы довести инцидент до разрешения. В спорных вопросах его голос решающий, и он обязан понимать контекст инцидента _целиком_. В зависимости от команды и масштаба инцидента он также распределяет задачи и задаёт вопросы другим участникам инцидента.

Участники инцидента — профильные эксперты (SME), которых привлекают к инциденту, чтобы решать задачи или отвечать на вопросы командира инцидента.

Дальше вы узнаете подробнее, как каждый из них взаимодействует с Dispatch.
