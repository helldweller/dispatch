# Поддержка

## Общая поддержка {#general-support}

Поддержку мы оказываем через [трекер задач этого репозитория](https://github.com/helldweller/dispatch/issues). Мы стараемся отвечать быстро, но учтите: открытый исходный код не входит в наши основные обязанности, поэтому код и поддержку мы предоставляем по мере возможностей.

## Как сообщить о проблеме безопасности {#reporting-a-security-issue}

Просим не сообщать о проблемах безопасности через обычный трекер задач GitHub.

Если вы считаете, что нашли уязвимость в `Dispatch`, сообщите о ней приватно через [рекомендации по безопасности GitHub (Security Advisories)](https://github.com/helldweller/dispatch/security/advisories/new).

> **Примечание.** В кодовой базе нет секретов. Секреты для разработки генерируются локально скриптом `docker/dev-setup.sh` в файл `docker/.env`, исключённый из git; в закоммиченном `docker/.env.example` только заглушки.

## Поддерживаемые версии {#supported-versions}

Проект ведёт один сопровождающий по мере сил, без SLA, но сообщения читаются, и по ним принимаются меры. Сообщения об ошибках и уязвимостях принимаются только для **последнего выпуска с тегом** и текущей вершины ветки `main` — полная политика описана в [SECURITY.md](https://github.com/helldweller/dispatch/blob/main/SECURITY.md).
