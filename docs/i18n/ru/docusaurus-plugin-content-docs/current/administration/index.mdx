# Администрирование

Все средства администрирования Dispatch собраны в веб-интерфейсе: здесь живёт то, что, скорее всего, будет меняться часто \(то, что меняется реже, задаётся в конфигурационном файле Dispatch\).

Чтобы открыть настройки Dispatch, найдите пункт меню `Settings` («Настройки») и выберите проект, которым хотите управлять.
