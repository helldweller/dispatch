# Управление пользователями

Пользователи (участники организации) — это учётные записи веб-интерфейса Dispatch; это не то же самое, что контакты (люди) или участники инцидентов. Такие учётные записи служат только для управления доступом к интерфейсу Dispatch. Создавать и удалять пользователей через интерфейс Dispatch пока нельзя — за исключением самостоятельной регистрации.

<div style={{textAlign: 'center'}}>

![](/img/admin-ui-users.png)

</div>

**Роль:** В интерфейсе Dispatch действует ролевая модель доступа (RBAC). Пока она используется только для защиты чувствительных инцидентов с ограниченной видимостью (restricted). Для конфигурации и настроек Dispatch ограничений доступа пока нет. В Dispatch определены четыре роли:

- «Участник» (Member): доступ ко всему, кроме инцидентов с ограниченной видимостью, — если только пользователь не участвует в них напрямую.
- «Администратор» (Admin): полный доступ к интерфейсу Dispatch и ко всем инцидентам, независимо от того, открыта их видимость или ограничена.
- «Менеджер» (Manager): пока то же самое, что «Администратор».
- «Владелец» (Owner): полный доступ к интерфейсу Dispatch и к управлению организациями.

**Настройки:**

- Проекты по умолчанию (Default Projects): список проектов, по которым Dispatch будет фильтровать данные во всём интерфейсе (например, в таблицах кейсов и инцидентов и на дашбордах).
