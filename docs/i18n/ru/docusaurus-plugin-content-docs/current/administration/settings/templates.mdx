# Шаблоны

Dispatch использует шаблоны, чтобы создавать документацию для конкретного кейса или инцидента. Эти шаблоны копируются и заполняются настолько, насколько Dispatch это умеет. После создания это обычные документы, привязанные к вашему кейсу или инциденту: в них можно работать совместно, фиксировать факты и выводы.

Dispatch поддерживает несколько типов шаблонов:

- Кейс (Case)
- Инцидент (Incident)
- Для руководства (Executive)
- Разбор (Review)
- Отслеживание (Tracking)

**Название (Name):** название шаблона.

**Описание (Description):** описание шаблона.

**Ссылка (Weblink):** ссылка на шаблон.

**Внешний идентификатор (External Id):** внешний идентификатор шаблона документа. Используется для интеграции через API (например, идентификатор файла Google Doc). Обычно это уникальный идентификатор из ссылки.

Если включить для шаблона режим evergreen, Dispatch будет отправлять владельцу шаблона напоминание по почте: пора пересмотреть шаблон и убедиться, что он актуален.

**Владелец evergreen (Evergreen Owner):** адрес электронной почты владельца этого шаблона документа.

**Интервал напоминаний evergreen (Evergreen Reminder Interval):** число дней между напоминаниями владельцу шаблона документа.

### Шаблон кейса {#case-template}

Копия этого шаблона создаётся для каждого нового кейса при его создании. Она содержит текущее состояние кейса; владелец или ответственный по кейсу фиксирует в ней факты и выводы.

- [Пример документа кейса](https://docs.google.com/document/d/1g1cl9liXG8US0eBnrZYRaeWa7Ek_hoZJ5PPadas44vI)

#### Переменные шаблона {#template-variables}

Ниже перечислены переменные, которые Dispatch попытается подставить при создании документа. Обратите внимание: повторно они сейчас не подставляются.

ПРИМЕЧАНИЕ: все переменные должны быть заключены в `{{}}`

- `case_name` — название кейса
- `case_title` — заголовок кейса
- `case_description` — описание кейса
- `case_resolution` — решение по кейсу
- `case_owner` — владелец кейса
- `case_type` — тип кейса
- `case_severity` — серьёзность кейса
- `case_priority` — приоритет кейса
- `case_status` — статус кейса
- `case_storage_weblink` — ссылка на хранилище

### Шаблон инцидента {#incident-template}

Копия этого шаблона создаётся для каждого нового инцидента при его создании. Она содержит текущее состояние инцидента; участники инцидента делятся в ней знаниями о нём.

- [Пример документа инцидента](https://docs.google.com/document/d/1fv--CrGpWJJ4nyPR0N0hq4JchHJPuqsXN4azE9CGQiE)

#### Переменные шаблона {#template-variables-1}

Ниже перечислены переменные, которые Dispatch попытается подставить при создании документа. Обратите внимание: повторно они сейчас не подставляются.

ПРИМЕЧАНИЕ: все переменные должны быть заключены в `{{}}`

- `name` — название инцидента
- `title` — заголовок инцидента
- `description` — описание инцидента
- `resolution` — решение по инциденту
- `commander_fullname` — имя текущего командира инцидента
- `type` — тип инцидента
- `priority` — приоритет инцидента
- `status` — статус инцидента
- `conversation_weblink` — ссылка на канал обсуждения (если есть)
- `conference_weblink` — ссылка на конференцию (если есть)
- `storage_weblink` — ссылка на хранилище (если есть)
- `document_weblink` — ссылка на документ инцидента (если есть)
- `ticket_weblink` — ссылка на тикет инцидента (если есть)

### Шаблон отчёта для руководства {#executive-template}

Часто во время инцидента нужно подготовить отчёт для руководства — общий обзор инцидента и действий, которые сейчас предпринимаются. Копия этого шаблона создаётся, заполняется и сохраняется в хранилище инцидента каждый раз, когда составляется новый отчёт для руководства.

- [Пример отчёта для руководства](https://docs.google.com/document/d/1dab6k14p5ageo5B_d1YlB_zS9hMGHDMXy9RUbIZous4)

### Шаблон разбора {#review-template}

Копия этого шаблона создаётся автоматически, когда инцидент помечается как стабильный. Командир инцидента и участники используют её, чтобы свести воедино выводы, обсуждения и задачи после инцидента.

- [Пример документа разбора инцидента](https://docs.google.com/document/d/1MkCTyheZRtKzMxOBhLgh3PrvarERA9Bwo0joM7D9tmg)

### Шаблон отслеживания {#tracking-template}

В некоторых инцидентах нужно отслеживать множество активов; этот шаблон — простая таблица, в которой участники инцидента могут совместно работать с табличными данными.

- [Пример таблицы отслеживания инцидента](https://docs.google.com/spreadsheets/d/1Odk4KlL7uMF_yd7OvTOCaPWmtTA_WzFBIA4lMeU5cGY)

### Привязка шаблонов {#template-association}

Шаблоны кейсов и инцидентов можно привязать к соответствующим типам. Так шаблон точнее соответствует конкретному типу кейса или инцидента и даёт для него дополнительный контекст и указания.

Кроме того, один шаблон можно привязать к нескольким типам кейсов или инцидентов — например, если вы хотите обойтись одним шаблоном.
