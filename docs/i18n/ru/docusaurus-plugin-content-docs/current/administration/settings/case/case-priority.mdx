# Приоритет кейса

Помимо типов кейсов, Dispatch позволяет задать приоритет кейса.

<div style={{textAlign: 'center'}}>

![](/img/admin-ui-case-priorities.png)

</div>

**Название (Name):** название приоритета кейса, которое видит пользователь.

**Описание:** описание приоритета кейса, которое видит пользователь.

**Порядок отображения (View Order):** порядок, в котором приоритет выводится в меню и выпадающих списках.

**Цвет (Color):** цвет приоритета кейса в интерфейсе.

**Приоритет кейса по умолчанию:** если заявитель кейса не указал приоритет, будет использован приоритет по умолчанию. Включите эту настройку, чтобы этот приоритет кейса стал приоритетом по умолчанию.

**Включён:** включён ли этот приоритет кейса.
