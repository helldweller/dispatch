# Серьёзность кейса

Помимо типов кейсов, Dispatch позволяет задать серьёзность кейса.

<div style={{textAlign: 'center'}}>

![](/img/admin-ui-case-severities.png)

</div>

**Название (Name):** название серьёзности кейса, которое видит пользователь.

**Описание:** описание серьёзности кейса, которое видит пользователь.

**Порядок отображения (View Order):** порядок, в котором серьёзность выводится в меню и выпадающих списках.

**Цвет (Color):** цвет серьёзности кейса в интерфейсе.

**Серьёзность кейса по умолчанию:** если заявитель кейса не указал серьёзность, будет использована серьёзность по умолчанию. Включите эту настройку, чтобы эта серьёзность кейса стала серьёзностью по умолчанию.

**Включён:** включена ли эта серьёзность кейса.
