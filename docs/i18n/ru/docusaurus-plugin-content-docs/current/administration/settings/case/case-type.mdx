# Типы кейсов

Dispatch позволяет классифицировать кейсы: вы определяете типы кейсов и привязываете их к различным ресурсам Dispatch (например, к шаблонам, дежурным службам и типам инцидентов).

![](/img/admin-ui-case-types.png)

</div>

**Название (Name):** название типа кейса, которое видит пользователь.

**Описание:** описание типа кейса, которое видит пользователь.

**Видимость:** позволяет указать, насколько виден будет кейс этого типа. Примечание: сейчас этот параметр не используется.

**Шаблон кейса:** позволяет создать новый или привязать существующий шаблон документа кейса к типу кейса.

**Дежурная служба:** позволяет привязать существующую дежурную службу, по которой будет определяться владелец кейса.

**Тип инцидента:** тип инцидента, который будет создан и связан с кейсом, если кейс этого типа переведут в статус «Эскалирован» (Escalated).

**Исключить из метрик (Exclude From Metrics):** включите эту настройку, чтобы исключить все кейсы этого типа из метрик (например, тестовые кейсы).

**Тип кейса по умолчанию:** если создатель кейса не указал тип кейса, используется тип кейса по умолчанию. Включите эту настройку, чтобы этот тип кейса стал типом по умолчанию.

**Включён:** включён ли тип кейса.

**Метаданные плагина (Plugin Metadata):** позволяет задавать пары «ключ — значение» и передавать их плагинам. Например, создавать тикеты в разных проектах Jira в зависимости от типа кейса.
