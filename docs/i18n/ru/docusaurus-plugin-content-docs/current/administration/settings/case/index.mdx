# Кейс

Кейсы нужны для разбора событий, которые не дотягивают до уровня инцидента, но при необходимости могут быть эскалированы до инцидента. Если привязать тип кейса к типу инцидента и эскалировать кейс, Dispatch автоматически создаст инцидент и свяжет их между собой.

Хотя у Dispatch есть твёрдое мнение о том, _как_ вести кейсы, он оставляет немало свободы. Ниже описаны разделы, которые позволяют подстроить работу с кейсами под вашу организацию.
