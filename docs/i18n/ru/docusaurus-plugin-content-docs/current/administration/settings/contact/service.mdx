# Сервис

Как и в случае с `Teams`, за приложение или сервис часто отвечает группа людей (команда), которую нужно подключать к инциденту. Но в таких ситуациях мы не хотим вовлекать _всю_ команду — только того, кто сейчас дежурит по этому сервису. `Services` позволяют Dispatch находить таких людей через сторонние дежурные службы (например, PagerDuty, OpsGenie).

</div>

**Название (Name):** название сервиса.

**Описание:** описание сервиса.

**Плагин:** плагин сервиса, с помощью которого Dispatch будет определять дежурного.

**Внешний идентификатор (External Id):** внешний идентификатор, по которому Dispatch и выбранный плагин определяют дежурного.

**Включён:** флаг, показывающий, активен ли этот сервис.

#### Вовлечение {#engagement}

Помимо полей сервиса, Dispatch позволяет связать сервис с другими объектами Dispatch. Например, если вы хотите привлекать сервис ко всем инцидентам определённого приоритета, свяжите этот приоритет с сервисом.
