# Тип сущности

Типы сущностей позволяют извлекать сущности из сырых данных экземпляра сигнала (Signal Instance). Извлечённые сущности сохраняются для дальнейшего использования: на них строятся автоматические корреляции, фильтры вовлечения и фильтры сигналов.

### Создание типа сущности {#creating-an-entity-type}

Чтобы создать тип сущности, выполните следующие шаги:

1. Откройте страницу редактирования определения сигнала.
2. Нажмите значок «+» рядом с выпадающим списком «Типы сущностей».

После этого в модальном окне откроется песочница типов сущностей (Entity Type playground) — интерактивный инструмент, который помогает создать и проверить тип сущности. Типы сущностей можно строить на регулярных выражениях или в формате JSON Path.

![](/img/admin-ui-signal-entity-type.png)

В показанном примере новый тип сущности определён в формате JSON Path. Выражение JSON Path columns.cmdline извлекает значение столбца cmdline из сырых данных экземпляра сигнала. Редактор песочницы подсвечивает извлечённое значение в сырых данных экземпляра сигнала, подтверждая, что совпадение с нужным значением найдено.

Когда тип сущности вас устроит, перейдите в песочнице к шагу названия и описания. Здесь укажите подходящее название и краткое описание типа сущности. По нажатию «Сохранить» тип сущности будет создан и привязан к соответствующему определению сигнала.
