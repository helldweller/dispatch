# Фильтр вовлечения

Фильтры вовлечения (Engagement Filters) автоматизируют обращение к пользователю, причастному к конкретному экземпляру сигнала (Signal Instance). Они используют типы сущностей, которые сопоставляются с адресами электронной почты пользователей в вашем окружении, и настроенное вами сообщение, которое отправляется этим пользователям. Фильтры вовлечения также поддерживают многофакторную аутентификацию при проверке подозрительного поведения. Это полезно, когда нужно убедиться, что пользователь, к которому вы обратились, действительно тот, за кого себя выдаёт, а не злоумышленник.

### Создание фильтра вовлечения {#creating-an-engagement-filter}

Чтобы создать фильтр вовлечения, выполните следующие шаги:

1. Откройте страницу редактирования определения сигнала.
2. Нажмите значок «+» рядом с выпадающим списком «Фильтры вовлечения».
