# Настройки

Веб-интерфейс Dispatch — место, где собраны все возможности администрирования Dispatch; здесь живёт то, что, скорее всего, будет меняться часто \(параметры, которые меняют реже, находятся в файле конфигурации Dispatch\).

Чтобы открыть настройки Dispatch, найдите пункт меню `Settings` и выберите проект, которым хотите управлять.
