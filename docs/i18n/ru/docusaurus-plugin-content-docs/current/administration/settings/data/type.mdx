# Тип

Чтобы получить доступ к источнику данных или выполнить к нему запрос, вам может понадобиться работать с несколькими разными системами. Тип источника обозначает технологию или систему, с которой он связан теснее всего.

Примеры типов источника данных:

- Hive
- ES (ElasticSearch)
- BigQuery
- Splunk
