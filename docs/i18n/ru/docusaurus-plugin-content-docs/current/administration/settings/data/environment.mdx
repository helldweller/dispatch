# Окружение

У источников данных часто есть окружение, к которому они относятся. Например, один набор данных может содержать сведения только из боевого (production) аккаунта. При реагировании на инциденты и использовании источников данных в расследовании важно понимать, какую область покрывает источник.

Примеры окружений источника данных:

- Production
- Staging
- Testing
- Development
