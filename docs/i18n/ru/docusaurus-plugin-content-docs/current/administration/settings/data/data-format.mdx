# Форматы данных

Источники данных не всегда однородны. Часто полезно понимать, в каком формате хранятся данные конкретного источника. Здесь Dispatch позволяет определить распространённые форматы данных, которые используют источники в вашем окружении.

Примеры форматов данных:

- JSON
- CSV
- Syslog
- XML
- Нестандартный
