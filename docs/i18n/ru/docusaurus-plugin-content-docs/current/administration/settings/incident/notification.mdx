# Уведомление

Уведомления позволяют указать, кому отправлять уведомления об инцидентах (помимо непосредственных участников).

<div style={{textAlign: 'center'}}>

![](/img/admin-ui-notifications.png)

</div>

**Название (Name):** название, которое увидит пользователь.

**Описание:** описание, которое видит пользователь при просмотре уведомления.

**Тип (Type):** тип плагина, через который отправляется уведомление (эл. почта или канал обсуждения).

**Получатель (Target):** адресат уведомления, подходящий выбранному типу плагина (например, имя канала Slack без `#` или адрес электронной почты).

**Фильтры (Filters):** фильтр поиска, по которому определяется, когда нужно отправить уведомление.

**Включён:** включено ли уведомление.
