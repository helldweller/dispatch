# Типы инцидентов

Dispatch позволяет классифицировать инциденты: вы определяете типы инцидентов и привязываете их к различным ресурсам Dispatch (например, к шаблонам).

<div style={{textAlign: 'center'}}>

![](/img/admin-ui-incident-types.png)

</div>

**Название (Name):** название типа инцидента, которое видит пользователь.

**Описание:** описание типа инцидента, которое видит пользователь.

**Видимость:** позволяет указать, насколько виден будет инцидент этого типа. Например, если выбрано `Open` («Открытый»), уведомления об инциденте этого типа будут отправляться при создании и обновлении инцидента, а обновления попадут в ежедневные отчёты по инцидентам. Все пользователи Dispatch смогут видеть инциденты этого типа в веб-интерфейсе независимо от роли. Кроме того, когда инцидент помечен как закрытый, Dispatch использует указанный домен Google, чтобы открыть доступ к папке инцидента и её содержимому всей организации. Если же выбрано `Restricted` («Ограниченный»), инциденты этого типа не попадут в уведомления, не будут видны пользователям Dispatch с ролью `member` в веб-интерфейсе, и Dispatch не откроет папку инцидента и её содержимое всей организации. По умолчанию выбрано `Open`.

**Шаблон инцидента:** позволяет создать новый или привязать существующий шаблон документа инцидента к типу инцидента.

**Шаблон отчёта для руководства (Executive Template):** позволяет создать новый или привязать существующий шаблон документа отчёта для руководства к типу инцидента.

**Шаблон разбора (Review Template):** позволяет создать новый или привязать существующий шаблон документа разбора инцидента к типу инцидента.

**Шаблон отслеживания (Tracking Template):** позволяет создать новый или привязать существующий шаблон таблицы отслеживания инцидента к типу инцидента.

**Исключить из метрик (Exclude From Metrics):** включите эту настройку, чтобы исключить все инциденты этого типа из метрик (например, инциденты «Симуляция» или «Тест»).

**Тип инцидента по умолчанию:** если заявитель инцидента не указал тип инцидента, используется тип по умолчанию. Включите эту настройку, чтобы этот тип инцидента стал типом по умолчанию.

**Включён:** включён ли тип инцидента.

**Метаданные плагина (Plugin Metadata):** позволяет задавать пары «ключ — значение» и передавать их плагинам. Например, создавать тикеты в разных проектах Jira в зависимости от типа инцидента.

**Модель затрат:** позволяет определить, как рассчитывать стоимость реагирования на инцидент. Если у типа инцидента нет модели затрат, при расчёте затрат используется классическая модель по умолчанию. См. [Модель затрат](../cost_model.mdx).
