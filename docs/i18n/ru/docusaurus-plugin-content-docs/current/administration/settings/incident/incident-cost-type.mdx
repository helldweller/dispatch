# Типы затрат на инцидент

Dispatch позволяет определить типы затрат на инцидент. Затем эти типы используются при добавлении и редактировании затрат по инцидентам. Каждые 5 минут Dispatch рассчитывает стоимость реагирования для всех инцидентов и сохраняет результат в тип затрат по умолчанию. Рекомендуем создать хотя бы тип затрат на реагирование и сделать его типом по умолчанию, чтобы пользоваться этой полезной возможностью. Список типов затрат на инцидент (или форм потерь, Forms of Loss), который рекомендует институт Factor Analysis of Information Risk (FAIR), доступен [здесь](https://www.fairinstitute.org/blog/a-crash-course-on-capturing-loss-magnitude-with-the-fair-model).

**Название (Name):** название типа затрат на инцидент, которое видит пользователь.

**Описание:** описание типа затрат на инцидент, которое видит пользователь.

**Категория (Category):** форма потерь (Form of Loss, FOL) или категория по методике Factor Analysis of Information Risk (FAIR).

**По умолчанию:** является ли этот тип затрат на инцидент типом по умолчанию.

**Редактируемый (Editable):** можно ли редактировать этот тип затрат.

### Расчёт стоимости инцидента {#calculating-incident-cost}

Dispatch [рассчитывает](https://github.com/helldweller/dispatch/blob/main/src/dispatch/incident/service.py#L279) стоимость инцидента, суммируя время, которое участники провели в каждой роли в инциденте \(например, командира инцидента\), и применяя [множитель вовлечённости](https://github.com/helldweller/dispatch/blob/main/src/dispatch/incident/service.py#L266), зависящий от роли в инциденте. Также учитывается время, потраченное на работу над разбором инцидента. Dispatch рассчитывает и публикует стоимость всех инцидентов [каждые 5 минут](https://github.com/helldweller/dispatch/blob/main/src/dispatch/incident/scheduled.py#L257).

Параметры расчёта стоимости инцидента можно настроить отдельно для каждого проекта — отредактируйте проект [здесь](../project.mdx)
