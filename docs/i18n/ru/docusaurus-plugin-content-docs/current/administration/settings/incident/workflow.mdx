# Рабочие процессы

Рабочие процессы позволяют расширять Dispatch, запуская вашу автоматизацию реагирования. Сейчас Dispatch не умеет создавать рабочие процессы сам. Вместо этого он позволяет запускать из Dispatch уже существующие рабочие процессы. Их выполнение мы доверяем внешним инструментам оркестрации, а Dispatch отслеживает статус рабочего процесса и полученные артефакты.

**Название (Name):** название, которое увидит пользователь.

**Описание:** описание, которое видит пользователь при просмотре рабочего процесса.

**Идентификатор ресурса (Resource Id):** _внешний_ идентификатор ресурса, по которому Dispatch связывает рабочий процесс с внешней системой.

**Плагин:** плагин, который находит и выполняет этот рабочий процесс. ПРИМЕЧАНИЕ: прежде чем привязывать плагин к рабочему процессу, его нужно установить и включить.

**Включён:** по умолчанию пользователи не могут запускать рабочие процессы. Включите настройку «Включён», чтобы разрешить использование рабочего процесса.

**Параметры рабочего процесса (Workflow Parameters):** позволяет задать пользовательские параметры (только строки), которые будут показаны пользователю и заполнены им. Они передаются в рабочий процесс.
