# Приоритет инцидента

Помимо типов инцидентов, Dispatch позволяет задать _приоритет_ инцидента.

<div style={{textAlign: 'center'}}>

![](/img/admin-ui-incident-priorities.png)

</div>

**Название (Name):** название приоритета инцидента, которое видит пользователь.

**Описание:** описание приоритета инцидента, которое видит пользователь при регистрации инцидента.

**Порядок отображения (View Order):** порядок, в котором приоритет выводится в меню и выпадающих списках.

**Напоминание о тактическом отчёте (Tactical Report Reminder):** число часов между напоминаниями.

**Напоминание об отчёте для руководства (Executive Report Reminder):** число часов между напоминаниями.

**Вызывать командира (Page Commander):** гарантирует, что командира инцидента вызовут по всем инцидентам с этим приоритетом (если это позволяют настроенная служба вызова и плагин).

**Цвет (Color):** цвет приоритета инцидента в интерфейсе.

**Приоритет инцидента по умолчанию:** если заявитель инцидента не указал приоритет, будет использован приоритет по умолчанию. Включите эту настройку, чтобы этот приоритет инцидента стал приоритетом по умолчанию.

**Включён:** включён ли этот приоритет инцидента.
