# Термины

Термины — это слова и фразы, которые ничего не говорят стороннему наблюдателю, но имеют глубокий смысл внутри организации (например, аббревиатуры и названия).

Возьмём для примера термин PCI. В мире безопасности эта аббревиатура обычно означает стандарт безопасности индустрии платёжных карт (Payment Card Industry).

Любой определённый термин можно связать с командами, сервисами или людьми, чтобы они включались в инцидент.
