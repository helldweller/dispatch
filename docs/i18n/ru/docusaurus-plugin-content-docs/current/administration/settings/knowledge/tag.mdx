# Теги

В Dispatch теги — это гибкие метаданные. Их можно вручную прикреплять к инцидентам или автоматически находить в данных инцидентов.

<div style={{textAlign: 'center'}}>

![](/img/admin-ui-knowledge-tags.png)

</div>

**Название (Name):** сама строка тега, то есть то, что вы ожидаете увидеть в данных инцидента.

**Описание:** краткое описание тега (если нужно).

**Тип (Type):** тип тега, который помогает отличать этот тег от других или относить его к категории. Типы тегов могут определять пользователи или плагины, синхронизирующие теги из внешних источников (например, названия приложений).

**Источник:** откуда взялся тег. Для тегов, созданных через интерфейс, источник по умолчанию — Dispatch.

**URI:** внешний локатор тега (если есть).

**Обнаруживаемый (Discoverable):** Dispatch умеет обнаруживать теги автоматически: получив набор заранее определённых тегов, он просматривает все доступные ему данные инцидентов и с помощью NLP связывает эти данные с инцидентами (с текущим и задним числом). Если тег слишком общий (например, «the») и вы не хотите, чтобы он обнаруживался, этот флаг отключает автоматическое обнаружение для отдельного тега.
