# Типы тегов

В Dispatch типы тегов позволяют группировать теги по категориям (например, «действующее лицо», «действие», «актив», «результат» и т. д.).

<div style={{textAlign: 'center'}}>

![](/img/admin-ui-knowledge-tag-types.png)

</div>

**Название (Name):** название типа тега.

**Описание:** краткое описание типа тега.

**Исключающий (Exclusive):** может ли у инцидента быть не больше одного тега этого типа.
