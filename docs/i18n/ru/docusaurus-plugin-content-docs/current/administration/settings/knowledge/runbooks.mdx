# Инструкции (runbook)

Инструкции (runbook) позволяют пользователям Dispatch динамически предоставлять участникам инцидента документы, которые могут пригодиться во время инцидента.

Если шаблоны служат для описания состояния инцидента, то инструкции обычно описывают шаги по его разрешению.

Насколько тесно связаны эти два понятия, зависит от инцидента и от того, как ваша организация ведёт инциденты.

Сейчас есть два типа инструкций, хотя используются они одинаково.

- Инцидент (Incident)
- Расследование (Investigation)

### Вовлечение {#engagement}

Документы-инструкции динамически подбираются к инциденту по их фильтру вовлечения. Как и для уведомлений, пользователь может задать, для каких инцидентов документ будет рекомендован участникам.

При создании инцидента (или при изменении важного параметра инцидента, например типа) Dispatch отправит в канал инцидента уведомление с предложением документа.

**Название (Name):** название документа.

**Описание:** краткое описание документа.

**Ссылка (Weblink):** гиперссылка на документ.

**ID:** внешний идентификатор, по которому загружается документ.

### Поддержание актуальности (Evergreen) {#evergreen}

Если включить для инструкции режим evergreen, Dispatch будет отправлять владельцу инструкции напоминание по электронной почте с просьбой проверить, что инструкция актуальна.
