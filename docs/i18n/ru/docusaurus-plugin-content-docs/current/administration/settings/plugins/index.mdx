# Плагины

Прежде чем настраивать и использовать плагины, прочитайте в документации по [CLI](../cli#plugins), как их устанавливать.

Большая часть возможностей Dispatch приходит из плагинов. Сейчас веб-интерфейс Dispatch умеет только включать и выключать плагины для каждого проекта. Чтобы изменить поведение плагинов или их конфигурацию, правки нужно выкатывать через файл конфигурации сервера. Подробнее — в документации по конфигурации [сервера](server).

По умолчанию ни один плагин не _обязателен_ для создания инцидента. Каждый включённый плагин добавляет свой шаг к процессу работы с инцидентом (например, создание каналов Slack, документов Google и т. п.).
