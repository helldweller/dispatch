# Настройка Opsgenie

:::info
Dispatch поставляется с поддержкой определения дежурных по расписаниям через API Opsgenie. Ниже описано, как настроить плагин Opsgenie для работы с `Dispatch.`
:::

## Настройка Dispatch {#dispatch-configuration}

Плагин Opsgenie настраивается в веб-интерфейсе Dispatch в разделе «Настройки» -> «Проект» -> «Плагины» (Settings -> Project -> Plugins). Добавьте плагин кнопкой `NEW`, затем откройте его настройки, нажав на три вертикальные точки.

### API Key {#api-key}

> Ключ для обращения к API Opsgenie.
