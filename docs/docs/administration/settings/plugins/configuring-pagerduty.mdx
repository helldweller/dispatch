# Configuring PagerDuty

:::info
Dispatch ships with support for resolving on-call schedules via the PagerDuty API.
:::

### Dispatch Configuration {#dispatch-configuration}

The PagerDuty plugin is configured in the Dispatch Web UI under Settings -> Project -> Plugins. Add the plugin using the `NEW` button and then edit its configuration by clicking on the three vertical dots.

#### API Key {#api-key}

> This is the key used to talk to the PagerDuty API. See: https://support.pagerduty.com/docs/generating-api-keys

#### From Email {#from-email}

> This the email to put into the 'From' field of any page requests.

#### Instance API URL {#instance-api-url}

> Enter the URL for your API (defaults to `https://api.pagerduty.com`, i.e. the US instance).

## Oncall Service Configuration {#oncall-service-configuration}

Go to /services on your Web server running Dispatch and add a new service. Select type `pagerduty-oncall` and add your PagerDuty Service ID in the external id field.
